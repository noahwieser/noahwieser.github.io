Response Expectations

We aim to respond within 3-5 business days.

Include In Your Message

  • Mead Maker app version
  • Device model and operating-system version
  • A short description of the issue
  • Steps to reproduce the issue, if possible
  • Whether the issue involves notifications, importing a backup, or a specific batch stage

Do not attach a Mead Maker backup unless you intend to share everything it contains, including embedded brew-log photos, recipes, batch details, tasting notes, and cellar records.

Backups And Recovery

  • Open Data & backups from the storage icon in the app bar.
  • Select Share backup file to export a portable JSON backup.
  • Select Import backup file to preview an import and choose Merge or Replace.
  • Merge updates matching records while keeping other local records; Replace makes the app match the backup.
  • A local safety snapshot is created automatically before each import and can be restored from the same screen.

Reminder Help

  • Open Reminder settings from the notification icon to enable reminders and choose an alert hour.
  • Make sure notifications are allowed for Mead Maker in your device settings.
  • Use Reschedule all reminders after changing time zones or system notification settings.
  • Stage reminders are check-ins. Confirm gravity and fermentation activity before advancing a batch.

Data And Deletion Help

Mead Maker is local-first and does not require an account.

  • Deleting a recipe or batch moves it to Recently Deleted.
  • Open Data & backups to restore it or delete it permanently.
  • Deleting a brew-log entry is immediate and cannot be undone.
  • To remove remaining local app data, uninstall Mead Maker or clear its browser storage on the web.

Bottle Cellar Help

  • Finishing a batch automatically creates a cellar lot using its bottle count, bottle size, and storage location.
  • Open the wine-glass icon to record bottles that were consumed, gifted, or added.
  • Use Storage on a cellar card to update its location and notes.

Known Scope

  • App data and recovery snapshots are stored locally for this release.
  • There is no account-based cloud backup or cross-device sync.
  • Scheduled stage reminders are available on Android, iOS, and macOS, but not on every supported platform.
