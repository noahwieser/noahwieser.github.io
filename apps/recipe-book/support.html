Support

Last updated: August 11, 2026

App: Recipe Book

Current listed version: 1.0.0

Contact

Support email: wieser.support@gmail.com

Response Expectations

We aim to respond within 3-5 business days.

Include In Your Message

  • App version
  • Device model and operating-system version
  • A short description of the issue
  • Steps to reproduce the issue, if possible
  • The public recipe URL when reporting an import problem

Do not attach a private recipe backup unless you intend to share everything it contains.

Backups And Recovery

  • To export your library, open Data tools and select Export backup.
  • To restore a JSON backup, open Data tools and select Import backup.
  • To review local recovery points, open Data tools and select Automatic backups.
  • JSON backups do not include local recipe photo files.

Data And Deletion Help

Recipe Book is local-first and does not require an account.

  • Deleting a recipe from its detail screen moves it to Recently Deleted.
  • To restore or permanently remove it, open Data tools and select Recently deleted.
  • To remove remaining local app data, uninstall Recipe Book from your device.

Website Import Help

  • Tap Add recipe, then Import from website.
  • Use a public HTTPS URL whose page visibly contains a recipe.
  • Some websites expose incomplete or incompatible recipe metadata. Always review the imported draft before saving.

Known Scope

  • Recipe data and automatic backups are stored locally on your device.
  • There is no account-based cloud backup or sync in this release.
  • Remote recipe pages and images remain subject to the availability of their original websites.
